# CleanUp Covid

**[Play in browser](https://hangyulkimmy.github.io/covid/)**

A small themed game made in 2022, clean up the virus before it spreads.

Made in **Unity** and exported to WebGL. This repo is the built player (`Build/`, `TemplateData/`, `index.html`) served from GitHub Pages.
